# ICLR 부록 일관성 검토

2026-09-26 부록 A–E에서 확인한 순위상관 부호, 시간상수 설명, 측정값 보고 문제를 사용자 요청에 따라 수정했다. 아래에는 검토 근거와 적용 결과를 함께 기록한다.

## 수정 적용 결과

E.4의 부호를 고치고 A.2·C.2의 시간상수 관계를 명시했다. E.3에 근거가 있는 측정값을 추가하고 E.5의 초과율 보고 범위를 확인된 NP 대표 회로로 한정했다.

- A.2는 기준 시간상수를 1로 두되 GELU 세제곱과 LayerNorm 분산의 실제 로그 연산에는 각각 세 배와 절반을 적용한다고 명시했다. C.2에는 GELU 지수 단계의 두 시간상수가 같다는 조건을 넣었다.
- E.4의 완전 검증 기준을 코드와 평균 발화 시각의 순위상관 −0.95 이하로 고쳤다. 현재 NP 선택에 사용한 완화된 조건과 미완료 검증 상태는 유지했다.
- E.3의 새 측정 표는 NP 184와 NL 1의 검증 표준편차, 보정으로 고정한 신호 구간, 정규화 값, 동작 시간 구간과 관측 기한을 제시한다. 초 단위 원자료를 마이크로초로 변환했고, 원자료의 비율을 별도로 확인했다.
- 근거는 `artifacts/brainscales2-primitives/20260924T_best_median_screen_summary.json`이다. SHA-256은 `639a908ac4b86440ef706afcd98467117cbf0f1e5424ca3e8de5f4ef8802f6c0`으로, 모델 실험에서 고정한 측정 요약과 일치한다. 원자료와 복제본은 수정하지 않았다.
- E.5에는 이 요약에서 확인되는 NP 184의 검증 관측 기한 초과율 0%만 넣었다. NL 초과율 및 모든 코드·회로별 값은 확인 가능한 기록에 없고, 요약이 가리키는 외부 원시 기록 경로도 현재 호스트에서 접근되지 않는다. 따라서 전체 코드·회로별 초과율을 보고한다는 문구와 E.3·E.4의 관련 포괄적 보고 문구를 삭제했다.
- 아래 문제 설명과 소스 행 번호는 수정 전 검토 시점을 보존한다. 미해결 과제 목록으로 읽지 않는다.

## 확정 오류: NP 순위상관의 방향

E.4의 완전 검증 조건은 NP 코드와 평균 발화 시각의 순위상관을 0.95 이상으로 요구한다. 이는 앞에서 정의한 입력 증가에 따른 발화 시각 감소와 반대다.

- 위치: [부록 E.4](/data/delayed-temporal/paper/iclr_2027/iclr2027_conference_appendix.tex:929)의 “rank correlation at least 0.95 between NP code and mean spike time”.
- B.1의 정의는 $\phi_{\mathrm{NP}}(S)=V_{\max}-S$이다. E.1은 코드가 증가할수록 입력 시냅스 가중치를 늘려 막전위를 준비한다고 설명한다. 이 NP 관계를 검증한다면 코드가 증가할수록 평균 발화 시각은 감소해야 한다.
- 수정 방향: 코드와 시각 사이의 순위상관을 **−0.95 이하**로 명시한다. 절댓값 기준을 쓰려면 감소 방향을 별도로 요구해야 하며, 절댓값만으로 바꾸면 반대 방향의 회로도 통과한다.
- 영향: 이 문장은 아직 완료하지 않은 완전 검증의 조건이다. 현재 보고한 NP 4개 회로의 완화된 선택 조건에 이 기준이 적용되었다고 해석하거나, 이 오류만으로 기존 모델 정확도 수치를 무효라고 판단해서는 안 된다.

## 한정 부족: 기준 시간상수와 실제 적용값

A.2는 ViT의 시간상수를 일괄적으로 1이라고 쓰지만, 거듭제곱과 LayerNorm 분산의 실제 로그 연산에는 배수·분수 시간상수가 들어간다. 기준 설정과 개별 연산의 값을 구분해야 한다.

- [A.2](/data/delayed-temporal/paper/iclr_2027/iclr2027_conference_appendix.tex:72)의 “All reported ViT conversion rows use ... $\tau_s=1$”는 기준값이라는 한정이 없다.
- B.3은 거듭제곱에서 $p\tau_m$를 사용하고, [B.4](/data/delayed-temporal/paper/iclr_2027/iclr2027_conference_appendix.tex:273)는 분산에 $\tau_s/2$를 사용한다. `utils/transforms/functions.py`의 GELU 세제곱 구현과 `utils/transformers/models/spiking_ops.py`의 LayerNorm도 각각 이 시간상수를 사용한다.
- 본문 §6.1은 power operation의 예외를 이미 설명한다. A.2도 기준값을 1로 두고 각 합성의 시간상수 비율을 따른다고 한정하면 된다. LayerNorm 분산의 제곱근 구성도 독자가 찾을 수 있게 참조한다.
- 추가로 B.2의 지수는 $\exp(-v/\tau_m)$인데 [C.2](/data/delayed-temporal/paper/iclr_2027/iclr2027_conference_appendix.tex:397)는 $\exp(-z/\tau_s)$와 $2\tau_s$ 입력 이득으로 설명한다. 이 단계에서 $\tau_m=\tau_s$를 쓴다는 조건을 명시해야 일반적인 두 시간상수를 혼동하지 않는다. 현재 평가의 기준값은 둘 다 1이고 GELU 구현도 지수 readout에 같은 값을 전달하므로, 여기서 실험 수치가 틀렸다는 증거는 없다.

## 보고 누락: 절대 시간 변동과 신호 구간

E.3과 E.5는 절대 시간 변동·신호 구간·코드별 관측 기한 초과율을 보고한다고 쓰지만, 현행 원고에는 이들 수치가 제시되어 있지 않다. 이는 수식 모순과 별개의 보고 내용 불일치다.

- [E.3](/data/delayed-temporal/paper/iclr_2027/iclr2027_conference_appendix.tex:878)는 절대 시간 척도, 각 신호 구간, 정규화한 값, 지연을 함께 보고한다고 한다. [E.5](/data/delayed-temporal/paper/iclr_2027/iclr2027_conference_appendix.tex:948)는 각 코드·회로의 검증 관측 기한 초과율을 보고한다고 한다.
- 원고에는 D.2의 두 정규화 값과 E.5의 동작 시간 구간·관측 기한이 있지만, 절대 표준편차 및 적합 신호 구간의 수치표는 없다. 코드별·회로별 초과율 표도 없다. D.3의 초과율은 시뮬레이션 결과이므로 이 하드웨어 표를 대신하지 않는다.
- 보존된 요약에는 다음 대표 회로 값이 있다. NP 184의 검증 표준편차는 약 0.200021 마이크로초, 적합 신호 구간은 약 18.455333 마이크로초다. NL 1은 각각 약 0.0770333 및 3.129226 마이크로초다. 두 비율은 D.2의 0.010838111 및 0.024617377과 일치한다.
- 수정 방향: 확보된 대표 회로의 측정 요약표를 넣고, 코드별 초과율은 실제 근거가 있는 범위로 제시한다. 근거를 원고에 제시하지 않을 항목은 “보고한다”는 문장을 측정·보관 범위에 맞게 고친다. 이 요약 파일은 NP 대표 회로의 합산 초과율은 담지만 모든 코드·회로별 값을 담지는 않는다.

## 대조 결과 모순으로 판정하지 않은 항목

GELU·SwiGLU의 서로 다른 경계, 보정과 고정 하한, 공유 기준 스파이크, 연산량 수치는 현재 설명에서 서로 양립한다.

- **보정 대상:** §5.1의 보정 필요성과 A.2의 해석적 범위·자료 기반 범위 구별은 양립한다. 로그 하한은 고정하고 상한은 보정된 입력 범위에서 얻는다는 설명만으로 로그 하한 자체를 보정한다고 해석할 수 없다.
- **지수 입력 경계:** A.2는 GELU에 $[-80\tau_s,80\tau_s]$를 두고 기준값이 1임을 명시한다. B.5의 $[-20\tau_s,20\tau_s]$는 SwiGLU의 별도 제한이다.
- **GELU 기준:** A.2는 ViT·RoBERTa의 erf 기준과 변환 모델의 cubic tanh 근사, 그 차이 및 clamping이 $\Delta$에 포함됨을 명시한다. GPT-2는 양쪽 모두 cubic tanh이다.
- **공유 기준 스파이크:** C.1은 기준 스파이크 하나의 잡음을 한 번 뽑아 여러 수신처에 전달한다고 명시한다. D.2의 독립 잡음은 서로 다른 원천 이벤트에 대한 가정으로 읽을 수 있다. 수신처마다 독립 표본을 다시 뽑는다는 주장은 없으므로 직접 모순으로 판정하지 않았다. 다만 이는 출력값 간 상관이 없다는 뜻은 아니다.
- **측정 요약:** NP/NL 좌표 184/1, 선택 수 4/58, NP 측정 수 63/64, 시간 구간과 관측 기한은 보존된 요약과 일치한다. NP의 조건 완화와 미완료 검증도 E.4가 공개한다.
- **Llama:** 결과 표에서 낮은 두 잡음 배율의 평균 perplexity 차이는 결정론적 변환 기준 대비 1.5% 이내이고, 가장 큰 배율에서는 두 자료 모두 500을 넘는다. 세 seed에 대한 구간과 제한된 평가 집단도 D.4의 설명과 일치한다.
- **SST-2:** 본문 824/872와 823/872의 차이는 약 −0.1147 pp다. −0.11은 반올림 표기라는 설명이 있으므로 상충하지 않는다.
