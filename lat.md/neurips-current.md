# 전류와 시냅스 가중치의 해석

시간 파형, 시냅스 가중치, 보정과 실행 입력을 구분하는 원칙을 유지한다. 탐색적 파라미터·벡터 표기와 당시 설계 제안은 [[deprecated#과거 전류 설계]]에 보관한다.

## 고정된 연산자와 조절 가능한 크기

고정된 연산자 집합은 모든 파라미터가 같은 상수라는 뜻이 아니다. 제한된 시간 파형의 재사용과 목표 함수마다 새 파형을 만드는 것을 구분한다.

뉴런 시간 상수·임계값, 변환 보정, 사전 학습 가중치·편향과 실행 입력은 역할이 다르다. 보정이 어디까지 공유되는지도 명시해야 한다. [[domain#Dual Operator Algebra]], [[domain#Scale Parameters]], [[neurips-mathematics#활성함수의 보정 위치]]에 연결한다.

## 스파이크와 벡터 전류의 구분

여러 수신 시냅스의 전류를 벡터로 표현한다고 뉴런이 벡터 값을 스파이크에 실어 전송하는 것은 아니다.

같은 스파이크 시각에서 시작하는 응답의 크기를 각 시냅스 가중치가 정하고 여러 입력의 기여가 합쳐진다. 기존 스칼라 식을 묶는 표기와 새로운 함수별 파형의 도입은 구별한다. 기호는 [[neurips-writing#용어 감사와 표기 원칙]]에 따라 승인된 정의를 사용한다.

## 적분과 고정 배율

적분에 공급되는 전류가 이미 가중치를 포함하면 같은 가중치를 적분 밖에서 다시 곱하지 않는다. 고정 배율과 실행 시 두 입력을 곱하는 연산은 다르다.

시간에 대해 일정한 가중치 전류의 적분은 가중치와 시간차의 곱이다. 부호와 도착 순서를 회로로 구현하는 조건은 별도다. [[operators#Primitive PWM Integration]], [[operators#Spiking Linear and Convolution]]이 현재 구현 계약이다.

## 노이즈와 비용의 해석 한계

독립 변화와 공유 편향은 평균화 효과가 다르다. 같은 이벤트 수라도 전류 크기와 지속 시간이 다르면 실제 에너지가 같다고 결론낼 수 없다.

현재 시간 노이즈는 [[noise#Direct Gaussian Spike-Time Noise]]로 정의하며 전류 기반 설계 제안으로 대체하지 않는다. 공유 오차의 한계는 [[neurips-hardware]]에 연결한다. SOP 환산과 전류 생성·유지·전달·보정·복제를 포함한 시스템 비용은 다르며, [[evaluation#Symbolic Operation-Count Check]]는 내부 산술만 검증한다.
