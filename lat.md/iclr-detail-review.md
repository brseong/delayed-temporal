# ICLR 본문의 과도한 세부 설명 검토

2026-09-25 본문 전체에서 문단의 역할보다 앞서 나간 설정·구현 설명, 반복 해명, 결과 나열을 검토했다. 부록은 상세해도 된다는 사용자 기준에 따라 본문만 판정한다.

## 범위와 판정 기준

현재 제출 원고에 연결된 본문·부록·표·그림 설명을 읽되, 과도한 상세함에 대한 지적은 초록부터 결론까지의 본문과 본문 표·그림으로 한정했다.

- 판정 대상: `paper/iclr_2027/iclr2027_conference.tex`의 초록과 Introduction, Related Work, Preliminaries, Framework, Methodology, Experiment, Conclusion 전체. 본문 표와 그림의 캡션·내부 문구도 포함한다.
- 부록은 863행까지 읽어 본문 내용과의 중복 및 이동할 위치를 확인했다. 부록의 유도 길이, 세부 설정, 검증 조건은 축약 대상으로 판정하지 않는다.
- 제외: 사용하지 않는 백업 원고, 주석 속 초안·작업 지시, 서지 항목, 서식 코드.
- 위치는 검토 시점의 소스 행 번호다. 짧은 원문 구절을 함께 기록하여 이후 편집으로 행 번호가 바뀌어도 찾을 수 있게 했다. 최초 검토에서는 원고를 수정하지 않았으며, 후속 적용 상태는 아래에 별도로 기록한다.
- **우선 수정**은 역할 이탈이 뚜렷한 경우, **축약**은 필요한 정보에 중복·불필요한 설명이 붙은 경우, **조건부**는 독자층과 지면에 따라 유지할 수 있는 경우다. 조건부 항목은 확정적인 삭제 권고가 아니다.
- 상세하다는 사실만으로 문제 삼지 않는다. 정의·가정·비교 조건·측정 한계·재현에 필요한 설정은 해당 설명이 필요한 위치에 남긴다. 실제 작성 주체가 LLM인지 판별하는 검토도 아니다.

기존 [[iclr-flow-review#ICLR 2027 원고 문단 흐름 검토]]는 다른 시점의 논증 연결 검토다. 이 문서는 현재 문장을 대상으로 정보의 양과 배치를 검토하며, 과거의 결과 미완료 판정을 그대로 사용하지 않는다. 설명 분리 원칙은 [[decisions#Key Design Decisions#Separate Complete Reasoning from Manuscript Exposition]]에 따른다. 후속 작업은 [[todo#Manuscript Revision Master Checklist#P1 Scalability and Exposition]]에서 관리한다.

## 서론·방법론·실험 결과 적용 상태

2026-09-25 사용자 요청에 따라 세 부분의 권장 조치를 적용했다. 아래 검토표는 수정 전 위치와 근거를 보존하며, 현재 적용 여부는 이 절을 기준으로 읽는다.

- 적용 완료: 본문 01–02, 11–12, 14–24의 15개 항목. 서론의 실험 세부 사항, 방법론의 끝점 규칙·반복 설명, 실험 결과의 설정·수치 나열을 줄였다.
- 본문에는 부호 분기 식, 잡음 크기를 정하는 식과 시간창 비례 가정, 주입 범위, 지표 정의, 신뢰구간의 의미, 핵심 결과를 유지했다.
- 보정 끝점과 고정 경계값, 측정 비율, 잡음 적용의 제외 사항, 실험 격자·시드·정밀도·집계 순서와 세부 정확도는 기존 부록의 해당 설명에 통합했다. 부록의 상세함은 줄이지 않았다.
- 본문 03–10, 13은 적용하지 않았다. 관련 연구·예비 정의·Framework의 조정과 일부 선택적 예시 축약은 남아 있다. 본문 25는 아래 결론 적용 상태에서 별도로 기록한다.
- 변경 전후 용어 검사와 추가된 줄 검사에서 금지 항목이 없었으며, 후보는 기존 용어·기호와 이동한 내용으로 확인했다. 수정된 원고의 PDF 생성도 완료했다.

## 결론 적용 상태

2026-09-25 후속 요청에 따라 본문 25를 적용했다. 결론은 기여와 핵심 한계, 대표적인 후속 연구 방향을 요약한다.

측정 경로 수·회로 선택·시간창 비례 가정·다른 적용 방식의 가능성을 재설명하던 문장을 줄였다. 연산량이 전체 구현 비용을 포함하지 않는다는 점과 잡음 결과가 제한된 하드웨어 측정에 근거한 시뮬레이션이라는 점은 유지했다. 후속 연구는 전체 모델의 하드웨어 실행 검증과 강건성을 높이는 학습으로 정리했다. 세부 측정 조건과 잡음 적용 가정은 기존 방법론·부록에 남아 있다.

## 핵심 판단

가장 큰 문제는 서론의 실험 절차, 방법론의 반복 해명, 결과의 설정·수치 나열, 결론의 측정 가정 재설명이다. 상세한 검증과 재현 설명은 부록에 둘 수 있다.

본문에서 **우선 수정 8개, 축약 10개, 조건부 7개**, 총 25개의 편집 검토 항목을 구분했다. 한 항목은 한 문장 또는 같은 문단의 여러 세부 사항이다. 25개 모두를 확정적인 삭제 대상으로 보거나 기술 오류로 해석해서는 안 된다.

우선순위가 가장 높은 곳은 서론 기여 요약(본문 02), 합성 표의 이벤트 수 해명(본문 08), 방법론의 측정 경로 설명(본문 14), 잡음 결과의 캡션과 세 문단(본문 21–24), 결론 한계 문단(본문 25)이다.

반복되는 양상은 다음과 같다.

1. 연구의 기여를 설명하다가 특정 모델의 실험 축과 주입 위치까지 내려간다.
2. 계산 원리를 설명하다가 다른 해석을 하나씩 부정하는 문장이 이어진다.
3. 결과를 해석할 자리에 재현 설정, 측정 시간, 소수점 이하 수치가 들어간다.
4. 결론에서 한계를 요약하는 대신 측정과 모델 적용의 세부 가정을 다시 설명한다.

중심 합성 예시는 이해에 도움이 된다. 문제는 같은 개념에 붙는 산술 예시의 반복과, 구현·비용·하드웨어 측정의 구별을 본문에서 연속 해명하는 부분이다.

## 상세하더라도 유지할 부분

축약은 독자가 주장을 정확히 해석하는 데 필요한 정의와 조건을 보존해야 한다. 다음 부분은 이번 검토에서 과도한 설명으로 판정하지 않았다.

- 초록의 대표 정확도·perplexity 결과, 서론의 문제–해법 설명, Framework 첫 세제곱 예시: 각각 연구 요약과 핵심 직관을 제공한다.
- Preliminaries의 두 정규화 순서와 기본 뉴런 식: 평가 모델과 연산자 구성을 이해하는 직접적인 배경이다.
- 연산자 표의 핵심 입출력 관계, 고정 계수의 이득 표기, 부호를 다루는 두 분기, 로그 입력의 양수 조건: 수학적 의미를 바꾸지 않으려면 남겨야 한다.
- Experiment:24의 행 내부 ANN–SNN 비교 원칙, 31행의 사전 학습 방식 주석, 65행의 평가 집단 차이: 독자가 비교표를 잘못 읽지 않게 하는 정보다. 이를 단순한 리뷰 방어로 삭제하지 않는다.
- Experiment:110의 추가 학습·재보정 없는 이산 시간 평가 조건: 실험이 무엇을 분리해 측정하는지 정한다.
- 잡음 그림의 두 축과 지표 정의, 반복 수·불확실성 표시의 의미: 캡션에서 그래프를 해석하는 데 필요하다. 전체 재현 설정 목록과 구별한다.
- 본문 그림 내부 문구는 주로 축·범례·핵심 합성 관계다. 별도로 삭제해야 할 과도한 구현 목록은 발견하지 않았다. 캡션의 과밀은 본문 21에서 따로 다뤘다.
- 부록의 상세 유도, 하드웨어 측정·선별 절차, 재현 설정은 이 검토의 축약 대상이 아니다. 본문의 간결함을 위해 설명을 옮기는 경우에도 이 세부 정보를 보존한다.

## 확인 범위와 한계

이 검토는 문장·식·표·그림 문구의 배치에 대한 편집 판단이며, 수치의 재현 실험이나 인용의 사실 검증은 수행하지 않았다.

2026-09-26 부록을 실험 설정, 연산자 유도, 연산량 계산, 추가 모델 평가, 하드웨어 측정의 다섯 절로 정리했다. 기존 수식·수치·측정 한계를 유지하며 독자가 필요한 설정과 근거를 찾기 쉽게 배치했다.

- 공통 설정에서 체크포인트·평가 집단, GELU·보정, CCT·소프트웨어 환경을 나눴다.

- 기존 참조 식별자를 유지하고 본문의 모델 평가 참조를 새 위치로 연결했다.
